EXHIBIT A

The mechanism of the leak

ADASYN/SMOTE create synthetic minority patients by interpolating between real ones. Done before the train/validation split, the interpolations of validation patients land in the training set — the model then “recognises” validation cases it has effectively already seen.

EXHIBIT B

Honest protocol, same data: chance

Split first; SMOTE and scaling re-fit inside each stratified CV fold (imblearn.Pipeline). Four tuned model families all land at ROC-AUC ≈ 0.5 — while the leaky protocol conjures 0.99 from the same rows. Mutual information between every feature and the diagnosis: ≤ 0.002.

RULINGS

What this audit establishes

  • Resample after you split, never before.
    Putting the oversampler inside the pipeline makes the mistake structurally impossible — it re-fits on training folds only.
  • A too-good number is a bug report.
    ROC-AUC 0.997 from ten anonymous features should trigger an audit, not a celebration.
  • Never fit any transformer on test data.
    The original also fit its polynomial feature transformer on the test set — a second, independent leak.
  • Accuracy is meaningless at 5% prevalence.
    An always-negative model is 95% “accurate”. Use ROC/PR-AUC and report precision–recall at an explicit threshold — the slider above is that decision, made visible.
  • Negative results are results.
    Proving the dataset unlearnable — and showing exactly how the fake score arose — is the real deliverable.
